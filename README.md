# 明日方舟香草杯

明日方舟干员淘汰赛生成器。打开即可使用，无需安装。

**在线体验：https://stedean-sawamura.github.io/Ark_vanilla_cup/**

## 使用方式

直接访问上方链接，或下载后在浏览器中打开 `index.html`。

干员数据已预缓存在仓库中，打开即用；页面会自动检查 PRTS 是否有新增干员，有则增量更新。

## 功能

- **按性别分组** 或 **全员混战** 两种模式
- **满编 / 均分** 两种分组方式
- **异格干员** 可选独立参赛或合并为同一角色
- 自定义每组人数上限，自动拆分 Tab + 总决赛
- 左右对称淘汰赛布局，冠军在正中汇合
- 点击空位选择胜者，支持清除和级联重置
- 轮空均匀分散，避免同对位双轮空
- 🎲 一键随机打乱重排
- 📤 分享：截图当前赛区 / 生成文字战报
- 💾 保存 / 读取进度（localStorage）
- 鼠标拖拽 + 滚轮缩放 / 手机触屏拖拽 + 双指缩放

## 数据来源

干员信息和头像来自 [PRTS Wiki](https://prts.wiki)（明日方舟中文 Wiki），通过 MediaWiki API 获取。
