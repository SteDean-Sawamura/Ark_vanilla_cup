# 明日方舟香草杯

明日方舟干员淘汰赛生成器。打开即可使用，无需安装。

## 使用方式

直接在浏览器中打开 `index.html`，页面会自动从 [PRTS Wiki](https://prts.wiki) 拉取全部干员数据和头像。

## 功能

- **按性别分组** 或 **全员混战** 两种模式
- 自定义每组人数上限，自动拆分 Tab + 总决赛
- 左右对称淘汰赛布局，冠军在正中汇合
- 点击空位选择胜者，支持清除和级联重置
- 轮空随机分散在各位置
- 🎲 一键随机打乱重排
- 保存 / 读取进度（localStorage）
- 鼠标拖拽平移 + 滚轮缩放
- Tab 懒加载头像

## 数据来源

干员信息和头像来自 [PRTS Wiki](https://prts.wiki)（明日方舟中文 Wiki），通过 MediaWiki API 实时获取。
